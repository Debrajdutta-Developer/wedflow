# WedFlow

WedFlow is an early project workspace for a wedding workflow or event-management application.

## Current repository state

The current root contains a pnpm workspace, Prisma-related dependencies, and folders for services, storage, types, and database configuration. The repository does not yet provide enough verified application behavior to claim a complete booking, vendor-management, payment, or guest-management platform.

## Stack currently visible

- Node.js ecosystem
- pnpm workspace
- Prisma ORM and Prisma Client

## Next development steps

1. Define the core user roles and event lifecycle.
2. Add and document the Prisma schema and migrations.
3. Implement one complete workflow before expanding the feature set.
4. Add tests, environment-variable documentation, and deployment instructions.

## Status

Scaffold / work in progress. Feature completeness and deployment have not been verified.
